Design System · v1.0

Quiet canvas,
one deliberate mark.

화면의 95%는 흰 여백과 잉크빛 활자입니다. 색은 눌러야 할 곳 단 한 군데에만 켜집니다.

Material Note

코도반은 결과 모공이 보이지 않는 가죽입니다. 값이 나가는 이유가 질감이 아니라 매끈함과 색의 깊이에 있습니다. 그래서 이 시스템은 평평합니다 — 가죽 무늬를 그리지 않는 것이 이 재질에 충실한 방식이고, 질감을 얹는 순간 재질에서 멀어집니다.

Signature 01

한 화면 한 색

옥스블러드로 채운 요소는 화면당 하나. 그래서 눌러야 할 곳이 즉시 보입니다.

Signature 02

초광폭 모노 라벨

머리말·지표 이름·표 헤더는 전부 대문자 모노. 계기판 같은 인상을 만듭니다.

Signature 03

반투명 머티리얼

고정 헤더와 시트는 뒤가 비칩니다. 깊이를 그림자가 아니라 재질로 만듭니다.

02

Color Rules

색 규칙은 한 문장으로 요약됩니다 — 눌러야 할 곳 하나에만 색을 켠다.

Rule 01

한 화면 한 색. --key로 채운 요소는 한 화면에 하나. 두 번째 액션부터는 Secondary·Ghost로 내립니다. 링크·활성 탭·포커스 링은 개수에 포함하지 않습니다 — 규칙의 대상은 면으로 채운 것뿐입니다.

Rule 02

key와 danger를 나란히 두지 않습니다. 둘 다 붉은 계열이라 채워진 면으로 공존하면 구분이 무너집니다. 파괴적 동작은 언제나 테두리형입니다 — 색이 아니라 형태로 구분합니다.

Never

순흑 #000000 · 그라데이션(배경·버튼·오버레이) · 질감(가죽결·노이즈·종이결·박음질) · 차트 색을 UI에 전용 · 채워진 빨강 오류 배경.

배경은 둘 중 하나

App

카드가 얹히는 앱 화면은 --bg(#F6F4F4)를 바닥으로 씁니다.

Document

글이 중심인 문서 페이지는 --surface(흰색)를 배경으로 씁니다. 이 문서가 그렇습니다.

Density

제목의 음수 자간이 이 시스템의 밀도입니다. 22px 이상 제목에는 표의 자간 값을 반드시 적용합니다. 자간 0인 큰 제목은 이 시스템이 아닙니다. 굵기는 400·600·700 세 개만 씁니다.

04

Components

모든 인터랙티브 요소는 hover 한 단계, active 두 단계, focus는 링, disabled는 가라앉힙니다.

Buttons

Form over color

Navigation · Material

고정 헤더는 --material-bg + backdrop-filter로 뒤가 비칩니다. 이 페이지 상단이 그 예입니다. 투명하게 두는 것과 다릅니다 — 비치되 읽혀야 합니다.

Icons

Phosphor Icons, Regular 굵기만. 16/20/24px, 색은 주변 텍스트를 따릅니다. 아이콘에 --key를 칠하지 않습니다 — Rule 01의 개수를 잡아먹습니다.

05

Feedback Patterns

기다림·빈 화면·오류를 다루는 방식. 1초 미만이면 아무것도 표시하지 않습니다.

Skeleton

콘텐츠와 같은 자리·크기·radius로, 투명도 1→.55→1을 1.6초 반복합니다. shimmer는 쓰지 않습니다.

[ ]

첫 프로젝트를 만듭니다

프로젝트를 만들면 지표가 여기에 쌓입니다.

Empty State

순서 고정: 아이콘 40px → 제목 22px/600 (가능성을 말할 것) → 설명 14px 1~2줄 → 버튼 1개. 중앙 정렬, 상하 패딩 64px 이상.

07

Layout & Responsive

4px 배수만 씁니다. 섹션 사이 여백이 이 시스템에서 가장 큰 값입니다.

구간폭열여백섹션 간격
Mobile<640px1열20px56px
Tablet640–1024px2열24px96px
Desktop≥1024px3열32px96–128px
  • 간격 스케일: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96, 128
  • 최대 폭 1200px, 본문 중심 페이지 720px, 카드 그리드 gap 24px
  • 타이포 축소: Display 56→36 / H1 40→30 / H2 30→24 / Metric 32→26. 본문 16px은 모든 화면 유지
  • 음수 자간은 모바일에서도 유지합니다. 크기만 줄이고 밀도는 그대로
  • 모노 라벨은 모바일에서도 11px. 더 줄이면 읽히지 않습니다
  • 터치 타깃 최소 44×44px
Before drawing a line

구분선보다 여백이 먼저입니다. 선을 긋기 전에 여백을 2배로 늘려 보십시오. 여백이 좁으면 활자의 밀도가 답답함으로 바뀝니다.

08

Motion · Voice · Accessibility

움직임은 짧게, 문장은 더 짧게.

Motion
  • 등장: 아래서 8px 올라오며 fade-in
  • 퇴장: fade-out만, 등장의 ½ 시간
  • 시트는 올라온 경로 그대로 내려감
  • 무한 반복·바운스 금지
  • prefers-reduced-motion 시 전부 비활성
Voice
  • 합니다체, 짧게
  • 저장되었어요 → 저장했습니다
  • 버튼은 명사·동사 원형 2~4글자
  • 문장 하나에 정보 하나
  • 느낌표·이모지 금지
A11y
  • 본문 4.5:1, 24px+ 3:1
  • 상태는 색이 아니라 형태·아이콘으로
  • Tab만으로 전 기능 도달
  • 머티리얼 위 텍스트도 4.5:1 확인
  • lang="ko"
09

Quick Decision Rules

판단이 애매할 때 이 순서로 해결합니다.

고민답
색가장 중요한 동작 하나 → --key. 나머지 전부 → 뉴트럴
이미 key를 썼는데 또 필요하면둘 중 덜 중요한 쪽을 Secondary로 내린다. 예외 없음
폰트제목 display, 나머지 sans, mono는 라벨 자리에만
굵기읽는 글 400 / 누르는 것·소제목 600 / 제목 700
자간22px+ 제목은 음수, 모노 라벨 +.1em, 본문 0
간격4px 배수 중 큰 쪽
모서리작은 것 6 / 누르는 것 10 / 담는 것 14 / 띄우는 것 20px
그림자테두리 → --shadow-1 순. 화면에 고정되면 그림자 대신 머티리얼
삭제 버튼언제나 테두리형. 채우지 않는다
차트 색1개면 chart-1만 / 여러 개면 순서대로 / 6개+면 상위 4 + 기타
겹침z-index 6단계 중 하나 — 새 값 발명 금지
