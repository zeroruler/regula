한 블록 한 색

01

색은 하나만

블록마다 팔레트에서 색을 하나씩 가져갑니다. 내부는 검정과 흰색뿐입니다.

02

옆과 겹치지 않게

인접한 블록에 같은 색을 연속으로 쓰지 않고 순서대로 돌립니다.

03

띠 아니면 전체

상단 띠와 전체 배경색 중 하나만 씁니다. 둘을 같이 쓰지 않습니다.

Rule

팔레트 색을 흰 배경 위 본문 텍스트로 쓰지 않습니다. 노랑은 흰 배경에서 1.63:1, 청록은 2.59:1, 핑크는 2.66:1로 3:1도 못 넘깁니다. 색은 면으로 쓰고 글자는 검정으로 씁니다. 예외는 24px 이상 제목의 빨강·파랑뿐입니다.

색 블록 예시

노랑 위에는 검은 글씨만

색 블록 안의 칩은 배경을 흰색으로 뒤집습니다. --on-yellow 값이 이미 정해져 있으므로 글자색을 고를 일이 없습니다.

Weight

검은고딕과 Archivo Black은 굵기가 하나뿐입니다. 제목의 무게는 굵기가 아니라 크기로 만듭니다. 가짜 굵기(font-weight: bold로 억지로 굵게)를 걸면 획이 뭉개집니다. 그리고 16px 이하에 검은고딕을 쓰지 않습니다 — 속공간이 막혀 읽히지 않습니다.

Label

모노스페이스를 쓰지 않습니다(초광폭 모노 라벨은 cordovan의 시그니처입니다). 이 시스템의 라벨은 검정 칩에 흰 글씨입니다. 색 블록 위에서는 흰 칩에 검은 글씨로 뒤집습니다. 한 화면에 5개까지.

04

Components

모든 면은 2px 테두리와 하드 섀도우를 갖습니다. 누르면 그림자가 사라지고 종이가 눌러붙습니다.

Buttons

↑ 눌러 보십시오. 그림자가 사라지며 3px 내려갑니다.

Rule

Primary 버튼의 색은 그 버튼이 속한 블록의 색을 따릅니다. 버튼만 혼자 다른 색을 갖지 않습니다. 파괴적 동작은 빨강 Primary가 아니라 Neutral 버튼 + 확인 모달로 처리합니다 — 빨강은 이 시스템에서 장식 색이기도 해서 위험 신호로만 읽히지 않습니다.

Icons

아이콘보다 도형이 먼저입니다. 원·삼각형·사각형·지그재그를 2px 검정 stroke로 직접 그립니다. 실제 아이콘 세트가 필요하면 Lucide를 stroke 2px로 올려 쓰되, 반드시 2px 테두리 도형 안에 넣습니다.

05

Feedback Patterns

1초 미만이면 아무것도 표시하지 않습니다.

Loading

스켈레톤도 2px 테두리를 갖습니다. shimmer는 쓰지 않습니다.

아직 아무것도 없음

첫 항목을 만들면 여기에 쌓입니다.

Empty

빈 화면에는 밀도가 full이어도 패턴을 깔지 않습니다. 이미 비어 있는 화면을 더 시끄럽게 만들지 않습니다.

Rule

글자가 얹히는 면에는 패턴을 절대 깔지 않습니다. 카드 배경, 표, 폼 뒤는 언제나 단색입니다. 패턴은 콘텐츠 아래 레이어(--z-pattern)에만 둡니다. 한 화면에 2종까지.

07

Layout & Responsive

4px 배수만 씁니다. 하드 섀도우가 옆 블록을 침범하지 않게 간격을 넉넉히 잡습니다.

구간폭열여백그림자
Mobile<640px1열20px3px로 축소
Tablet640–1024px2열24px기본
Desktop≥1024px3열32px기본
  • 간격 스케일: 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80, 96
  • 블록 사이 간격은 그림자 크기의 최소 4배 — 안 그러면 그림자가 옆 블록을 침범합니다
  • 비대칭 분할(2:1, 1:2)을 허용합니다. 단 밀도 quiet에서는 균등 그리드만
  • 타이포 축소: Display 64→38 / H1 44→30 / H2 32→24 / Metric 40→30. 본문 16px은 모든 화면 유지
  • 모바일에서 떠다니는 도형은 개수를 절반으로 줄입니다 (밀도가 full이어도)
  • 터치 타깃 최소 44×44px
08

Motion · Voice · Accessibility

세 시스템 중 가장 적게 움직입니다.

Motion
  • 버튼 눌림
  • 모달·드롭다운 등장
  • 스켈레톤 펄스
  • 이 셋뿐입니다
  • 패턴과 도형은 절대 안 움직임
Voice
  • 문장을 자르고 명사로
  • "파일 3개 업로드 완료"
  • 버튼은 동사 한두 글자
  • 숫자를 앞세움
  • 이모지 금지 — 도형을 씀
A11y
  • 본문 4.5:1, 24px+ 3:1
  • --on-*를 임의로 바꾸지 않음
  • 포커스는 바깥쪽 오프셋 아웃라인
  • 패턴·도형은 aria-hidden
  • 검은고딕은 24px 미만 금지
09

Quick Decision Rules

판단이 애매할 때 이 순서로 해결합니다.

고민답
무엇부터 정하나장식 밀도. full / half / quiet 중 하나를 먼저 고른다
색이 블록에 색 하나 → 내부는 검정·흰색. 옆 블록과 같은 색은 피한다
색 위 글자색고르지 않는다. --on-*를 그대로 쓴다
팔레트 색으로 글씨24px 이상 제목의 빨강·파랑만. 나머지는 검정
폰트제목 display, 본문 sans. 16px 이하에 검은고딕 금지
테두리언제나 2px. 1px도 3px도 없다
그림자하드 섀도우 3종 중 하나. 흐릿한 그림자는 존재하지 않는다
모서리0. 칩·뱃지만 pill
라벨검정 칩 + 흰 글씨. 모노스페이스는 이 시스템에 없다
패턴을 깔고 싶다글자가 얹히는 면인가? 그렇다면 깔지 않는다
삭제 버튼빨강 아님. Neutral 버튼 + 확인 모달
차트 색이 부족색을 늘리지 말고 패턴 채우기를 쓴다
